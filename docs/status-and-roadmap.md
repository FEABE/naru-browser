# Naru 현재 상태와 남은 작업

기준일: 2026-10-21. 기준 커밋: `13bd45f` (`codex/navigation-readiness`).

이 문서는 2026-10-20~21 작업으로 바뀐 상태와 앞으로 할 일을 한곳에 모은다. 판정 근거는 [독립 브라우저 E2E 체크리스트](ego-parity-e2e.md)의 "최종 통합 실행" 절, 변경과 검증 기록은 [작업 기록](work-log.md)에 있다. 전체 목표와 완료 기준은 [완성 계획](product-plan.md)을 따른다.

## 한 줄 판정

독립 브라우저 완성을 선언하지 않는다. 에이전트용 CLI는 ego lite의 주요 조작을 대부분 갖췄지만, 14개 실사용 여정 중 이 바이너리로 통과한 여정은 4개다. 나머지는 네이티브 화면 조작, IME, 60분 사용, 외부 로그인 확인이 남았다.

## 앞으로 할 일

### 1순위: 완성 판정에 필요한 확인

1. **네이티브 화면 E2E**: 여정 02, 03, 05, 09, 10과 이번에 추가한 네이티브 UI를 실제로 눌러 확인한다. 대상은 "AI에게 돌려주기", 대화상자 띠의 포커스와 Return, Esc, 음소거 행 버튼, AI 우클릭 때 네이티브 메뉴가 뜨지 않는지다. 에이전트가 하려면 Claude 데스크톱 앱의 Computer use 또는 터미널 앱의 손쉬운 사용 권한이 필요하다. 지금 세션에는 둘 다 없다.
2. **60분 사용 재실행**: 최종 바이너리로 `artifacts/final-20261021/j14_driver.py`를 60분 돌린다. 스크린샷 경로 결함은 이 드라이버에서 고쳤다.
3. **렌더러 강제 종료 복구**: 시험 탭의 렌더러만 종료한 뒤 실패 안내와 새로고침 복구를 확인한다.
4. **여정 11**: 사용자가 로그인 대상 사이트를 정한다. 로그인은 사용자가 직접 한다.

### 2순위: 알려진 결함

| 결함 | 상태 | 다음 단계 |
|---|---|---|
| 첫 로딩 중 화면 중지 버튼이 `NAVIGATION_BUSY`로 끝남 | CLI에서 재현 안 됨 | 화면 클릭으로 재현해 `navigation_control_matches`의 세대 불일치 가설 확인 |
| 사이드바 모서리 잘림 | 원인 미확정 | 재현 조건을 먼저 확보 |
| 같은 탭의 알림 요청이 위치 권한 1회 거절 기록을 먼저 소비 | 영향은 재요청 카드 1회 | 필요하면 권한 종류별로 기록을 분리 |
| AI 우클릭 뒤 사용자 우클릭 메뉴가 열리지 않을 수 있음 | 첫 차단 뒤 기록을 지워 범위를 줄임 | 네이티브 확인으로 실제 영향 판단 |

### 3순위: 사용자 결정이 필요한 기능

| 기능 | 현재 원칙 | 결정할 것 |
|---|---|---|
| `evaluate` (페이지에서 JS 실행) | 페이지 JS를 신뢰하지 않음 | isolated world 한정, 작업 범위와 결과 크기 상한을 두고 넣을지 |
| CLI 다운로드 저장 경로, 파일 선택 경로 지정 | 파일 경로는 사용자가 고름 | 허용 디렉터리를 제한해 넣을지 |
| 페이지 이벤트 구독, 여러 프로필 | 없음 | 필요 여부 |
| 탭 복원, 페이지 확대 | 사용자 보류 | 보류 유지 여부 |
| 에이전트 가이드 언어 | 한국어 | 읽는 쪽이 에이전트라 영어 사본을 둘지 |

### 4순위: Preseller 내장 준비

[Preseller 내장 문서](preseller-integration.md)의 단계를 따른다. 마지막 탭 닫힘과 앱 종료의 수명주기 분리, 창 생성과 화면 책임 분리가 먼저다. 수명주기 변경은 사용자 보류 항목과 연결돼 있어 범위를 정한 뒤 시작한다.

### 그 밖의 정리

- `main`에 아직 병합하지 않았다. PR을 만들어 검토한 뒤 합친다.
- `.local-data/` 아래 이전 검증의 소켓과 합성 프로필 폴더가 남아 있다. 사용자 승인 뒤 정리한다.
- `artifacts/`와 `dist/`는 git 추적 대상이 아니다. 검증 증거는 로컬에만 있다.

## 작업 방식

이번 작업은 계획을 Fable, 구현을 Sonnet, 리뷰를 Opus가 맡았다. 단계마다 리뷰에서 실제 결함을 찾아 고친 뒤 병합했다. 대표 사례는 대화상자가 걸린 AI 탭 때문에 앱이 종료되지 않던 문제, 드래그 중단 뒤 마우스 버튼이 눌린 채 남던 문제, 주소창 Return이 대화상자 응답으로 새던 문제다. 같은 방식을 이어 가려면 이 문서의 1순위부터 진행한다.
