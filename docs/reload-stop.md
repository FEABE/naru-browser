# 새로고침과 로딩 중지

기준일: 2026-10-16. 네이티브 도구 막대, 메뉴와 ⌘R의 의도를 실행까지 유지하는 보완이다. 최신 앱의 실제 CEF 실행 결과는 아래 소스 검사와 구분한다.

## 표시한 동작 유지

명령 시작 때 표시된 탭 ID, 공간, 탐색 세대와 중지 여부를 함께 잡는다. 런타임에서 로딩 상태를 다시 읽더라도 중지를 새로고침으로 바꾸지 않는다. 로딩이 끝난 중지 요청은 아무 명령도 보내지 않고 AI 작업의 제어권도 바꾸지 않는다. 새로고침을 선택한 뒤 새 로딩이 시작됐다면 중지로 전환하지 않고 거절한다.

CEF의 로딩 상태뿐 아니라 아직 처리 중인 탐색 의도와 provisional 상태도 확인한다. 이전 중지의 완료를 기다리는 동안 중복 중지를 실행하지 않는다. 완료 후 다른 리소스가 새로 로딩되는 경우는 다시 중지할 수 있어야 하므로 과거의 stopped 표시만으로 거절하지 않는다.

현재 공간과 선택, Browser identity, 문서와 탐색 세대, AI 소유권을 네이티브 조회와 콜백 경계에서 재검사한다. 실행이 필요한 현재 AI 탭만 기존 handoff 경로로 인계하며, 그 인계가 만든 revision과 탐색 세대 증가만 허용한다. 다른 탐색이나 소유권 변경이 섞이면 명령을 보내지 않는다. 명령을 이미 CEF에 보낸 뒤 발생한 변화는 전송 자체를 취소한 것으로 설명하지 않는다.

페이지 실패 화면의 다시 시도는 새로고침 의도를 명시한다. 검색, 북마크, 다운로드 화면이나 공간 목록이 열렸을 때, 입력기 조합 중일 때는 도구 막대 명령을 실행하지 않는다. 메뉴는 열릴 때 표시한 대상이 바뀌면 이전 항목의 동작을 거절한다.

AppKit의 창과 입력기 조회는 CEF 로딩 표본을 얻기 전에 수행한다. 표본을 얻은 뒤에는 콜백을 만들지 않는 현재 대상 검사만 거쳐 판단한다. 상태 검사 자체가 로딩을 완료시키고 오래된 표본으로 AI 작업을 중지하는 경로를 막기 위한 순서다.

CLI의 `stop`은 별도 접수 계약을 유지한다. 로딩 중이 아니어도 기존 다운로드 권한 대기와 찾기, 방문 후보를 정리하고 stop_load를 요청한다. 배경 탭을 대상으로 할 수 있으며 네이티브 도구 막대의 무동작 정책이나 AI 인계를 적용하지 않는다. 전송 전에 원래 탭이나 소유권이 바뀌면 성공 응답 대신 오류를 반환한다.

## 주소 초안

명령 호출 동안 같은 탭과 주소의 자동 URL 표시 갱신만 잠시 보류한다. 주소 문자열을 복사해 되쓰지 않으므로 재진입 중 새로 편집한 내용을 덮지 않는다. 화면을 최신 상태로 동기화한 뒤 런타임이 확인한 최종 탐색 세대로 초안의 기준만 맞춘다.

AI 인계가 끝난 뒤 창 포커스가 바뀌어 중지나 새로고침이 전송 전에 실패해도, 같은 Browser와 문서, 선택과 소유권이 유지됐다면 실패 결과에 주소 보존 근거를 함께 반환한다. 명령 실행 가능 여부와 주소 보존 가능 여부를 구분하므로 같은 페이지에서 검색 화면을 연 것만으로 이미 입력한 주소를 버리지 않는다. 실패한 동작을 성공으로 표시하거나 자동 재시도하지는 않는다. 실제로 요청한 새로고침에는 보존 근거를 주지 않는다.

탭, 공간이나 실제 문서가 바뀌면 이전 초안을 되살리지 않는다. 임시 보류는 성공과 실패 모두 호출이 끝나면 해제한다. 새로고침은 기존 실제 탐색의 초안 만료 규칙을 따른다.

[화면 스냅샷](shell-snapshot.md)을 보류한 경우도 처리한다. 결과를 받은 직후 같은 Browser, 문서와 소유권을 확인해 짧게 보관하고 화면 갱신 후 내부 상태만으로 재확인한다. 이 근거가 유효하면 캐시된 화면의 탐색 세대가 아직 이전 값이어도 초안의 기준을 결과 세대로 옮긴다. 로딩 상태만 바뀌어 조회가 보류된 경우의 초안 소실을 막으며, 새 편집이나 실제 페이지 변경을 덮지 않는다.

## 자원과 검증 경계

메뉴 대상 한 개와 동기 호출 문맥 한 개만 유지한다. 새 저장소, 상주 작업, 반복 타이머, 창이나 renderer를 추가하지 않는다. 이는 추가 상태의 범위이며 실제 앱의 RAM 절감량을 측정한 결과가 아니다.

소스 검사는 완료 직전 중지, 중복 중지, 새 로딩 중 새로고침 거절, 오래된 탭과 소유권, 네이티브 조회 중 재진입, 인계 후 문서 변경, 주소 초안의 보존과 만료를 구분한다. 실행 결과와 관련 파일은 [작업 기록](work-log.md)에 남긴다.

실제 Naru에서 느린 HTTP 응답의 중지, 메뉴가 열린 동안 로딩 완료, 주소 편집 중 버튼 클릭, AI 인계와 배경 공간 보존, 한글 조합, 렌더러 복구는 후속 검증이다. 단위 검사나 독립 Chromium의 결과를 이 검증의 완료로 대신하지 않는다.
